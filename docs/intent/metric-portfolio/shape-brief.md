# A useful metric portfolio — shape

**Outcome:** Default metrics earn their attention through distinct review decisions.

**Primary flow:** Load comparable observations → compare portfolios → inspect differing targets → retain useful signals and document exclusions.

## Feature scope

```text
Portfolio evaluation
├── PLANNED ADDITIONS
│   ├── Reproducible three-repository pilot
│   │   ├── Revision, analyzer, exclusions and support recorded
│   │   └── Separate language, file/function and size groups
│   ├── Association and decision comparison
│   │   ├── Rank overlap, size-adjusted relationships and missing rates
│   │   └── Shuffled source cases with useful and rejected outcomes
│   └── Recommended catalog
│       ├── Compact defaults versus organized full catalog
│       └── Each candidate has a reason, cost and revisit condition
└── EVALUATE BEFORE COMMITTING
    ├── Cognitive complexity beyond CCN, nesting and size
    └── Wider corpus only when the pilot yields useful distinctions
```

## Decisions and boundaries

**Appetite:** Three repositories and a small review sample first. Use existing scan artifacts and a standalone analysis script.

**Key decision:** Review changes in action as well as correlations. A high association cannot erase a rare useful case. A low association cannot excuse broken support or noise.

**Boundary:** No feature-selection platform, model training, or opaque composite. Review time and setup cost count against a candidate. The existing catalog remains accessible during evaluation; no compatibility layer is required.

**First proof:** A repeatable comparison artifact with deliberate counterexamples.

**Try:** Compare equal-size flat/deep functions and a constant or mostly unavailable metric before collecting a repository cohort.

**Observe:** Check undefined associations, support counts, queue overlap, and which source case changes the proposed action.

**Decide:** Reject the analysis method if it calls missing data independent or discards a useful case solely for high correlation.
