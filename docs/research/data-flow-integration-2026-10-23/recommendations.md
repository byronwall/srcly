All dispositions follow the [verified findings](verification.md) and [surface/runtime comparison](README.md#alternatives). They map to the [implementation plan](../../intent/data-flow-integration/implementation-plan.md).

Two related options remain deferred: artifact import for historical results, and separate-tool links for diagnostics. Neither becomes the primary journey.

## Reconciliation with existing plans

[Imported quality evidence](../../intent/imported-quality-evidence/implementation-plan.md) favors artifacts before new engines. This proposal reuses an existing engine on explicit inspection. It does not add automatic semantic analysis to normal scans.

[Unified navigation](../../intent/unified-navigation/implementation-plan.md) supplies useful location concepts. Extend those concepts with exact selection and entry-specific return state. Do not treat the recent-places ring as a complete browser history snapshot.

Keep the current route-field work in tsx-data-flow independent. Reuse valid contracts and evidence primitives. Do not widen its source rules silently or add Srcly-specific recognition rules.
