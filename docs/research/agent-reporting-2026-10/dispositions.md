# Recommendation dispositions

IDs refer to the [original register](../../intent/agent-reporting/assets/pro-results/2026-10-31/recommendations.md). Build means plan the work, not authorization to ship unreviewed code.

| IDs | Disposition | Reason |
| --- | --- | --- |
| CLI-001–003, 006–007, 010–011, 016–017, 022–024, 027, 036 | Build | Repair incorrect or opaque evidence, scope resolution, output and maintained guidance. Preserve shared UI and engine contracts. |
| CLI-004–005, 012–015, 018–021, 025–026 | Explore | Prototype snapshot reuse, provider selection, identity, budgets, flow, compare, evaluation and local context; choose scope from measured jobs and implementation cost. |
| CLI-008–009, 033–035 | Explore | Test categories, lane triggers, storage and related-test evidence against real tasks before setting defaults. |
| CLI-028–029 | Defer | A daemon or interoperability export adds scope without a demonstrated local need. |
| CLI-030 | Explore | Test alternatives to composite severity and metric gates before removing existing workflows. |
| CLI-031–032 | Avoid | Do not infer policy compliance or safe automatic edits from prose and metrics. |
